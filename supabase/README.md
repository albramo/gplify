# gplify — ربط Supabase (خطوات التشغيل)

## صفحات الثيمات المنفصلة
- كل ثيم ليه ملف صفحة مستقل (`/theme/<slug>/`) بيتولد تلقائياً مع كل `npm run build` (بعنوانه ووصفه وروابط المشاركة)
- بعد أي إضافة/تعديل/حذف ثيم من اللوحة: اعمل build وارفع `dist` من جديد عشان الصفحات تتحدث
- ملفات `vercel.json` و`public/_redirects` و`public/.htaccess` بتخلي الروابط شغالة على أي استضافة
- قبل الـ build اظبط `SITE_URL` في `.env` على دومينك النهائي (يستخدم في روابط المشاركة)
## 1) نفّذ السكيما (مرة واحدة)
- افتح Supabase Dashboard ← مشروعك ← **SQL Editor** ← New query
- انسخ محتوى `supabase/schema.sql` كاملاً ← **Run**
- السكربت آمن التكرار: ينشئ جداول `themes` و `coupons` و `orders` و `subscribers` + السياسات + الفهارس

## 2) جهّز ملف البيئة
```bash
cp .env.example .env
```
- املأ `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` (من Project Settings ← API)
- املأ `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` (للسكربت فقط — لا تشاركه ولا تضعه في كود الواجهة)

## 3) ارفع الكتالوج الافتتاحي (مرة واحدة)
```bash
npm install
npm run seed
```
يرفع 8 قوالب + 3 كوبونات (`GPL20`, `GPL10`, `VIPGPL`) لجداول سوبابيز.

## 4) شغّل المتجر
```bash
npm run dev
```

## ملفات التحميل (UploadThing)
1. اعمل حساب على uploadthing.com ← اعمل App جديد ← ارفع ملف الـ ZIP بتاع كل قالب
2. خد رابط الملف المباشر (بالشكل `https://utfs.io/f/...`)
3. في لوحة تحكم المتجر (`/admin122`) الصق الرابط في خانة **رابط التحميل المباشر** لكل ثيم
4. الرابط ده هو اللي العميل بيحمله منه فوراً + بيتبعتله في الإيميل

## إيميل روابط التحميل التلقائي (Resend + Edge Function)
1. اعمل حساب على resend.com ← ضيف دومينك ووثّقه (Domains) ← خد API Key من API Keys
2. نزّل Supabase CLI وسجل دخول: `supabase login` ثم `supabase link --project-ref XXX`
3. خزّن المفاتيح: `supabase secrets set RESEND_API_KEY=... FROM_EMAIL="gplify <orders@gplify.store>"`
4. انشر الفانكشن: `supabase functions deploy send-order-email`
5. جرّب طلب تجريبي — العميل يستلم إيميل عربي فيه أزرار تحميل مباشر لكل قالب

## الدفع اليدوي (فودافون كاش / انستاباي) — الوضع الحالي
- العميل يختار الطريقة ويحوّل، يسجل الطلب (بحالة `pending`)، ويدوس زرار الشات بتفاصيل طلبه جاهزة
- **الإعداد من اللوحة** (`/admin122` ← تبويب الإعدادات): فعّل واتساب أو تليجرام أو الاتنين مع بعض (كل واحدة برقمها) + رقم المحفظة + عنوان انستاباي — بتظهر فوراً في المتجر
- **الطلبات الجديدة** بتظهر في اللوحة ← تبويب الطلبات (عداد المعلق في اسم التبويب) — راجع التحويل ثم دوس **تأكيد الدفع** وسلم الملفات (روابط Backblaze) على الشات أو البريد
- ملاحظة: الإيميل التلقائي بروابط التحميل (Resend) معمول للدفع الفوري — مع الدفع اليدوي التسليم بيدك بعد التأكيد

## إدارة المحتوى بعد كده
- **حساب المالك (مرة واحدة):** الداشبورد ← Authentication ← Settings ← اقفل **"Enable new user signups"** (مهم جداً عشان محدش يعمل حساب ويعدل)، ثم Authentication ← Users ← **Add user** وحط إيميلك وباسوردك
- **القوالب:** افتح `yoursite.com/admin122` ← سجل دخول بالإيميل والباسورد ← إضافة/تعديل/إخفاء/حذف (الجلسة تفضل شغالة، والخروج من زر الخروج في الهيدر)
- **الكوبونات:** نفس اللوحة ← تبويب الكوبونات
- **الطلبات:** جدول `orders` في الداشبورد (إدخال فقط من المتجر — تُقرأ من الداشبورد)
- **المشتركين:** جدول `subscribers`
